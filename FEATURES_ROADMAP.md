# DesignDesk Roadmap: 20 High-Priority Features

This document outlines the top 20 high-priority features identified for the MCCIA Applied AI Studio DesignDesk platform to elevate UX, streamline operations, and boost overall platform performance.

## 🔒 Authentication & Access
1. **Role-Based Access Control (RBAC):** Restrict features (e.g., SLA configuration, global analytics) to "Design Lead" roles while offering simplified views for "Clients".

## 🚀 Kanban & Workflow
4. **Bulk Actions:** Select multiple tickets via `Shift + Click` or checkboxes to bulk update status, assignees, or priority.
5. **Custom Workflow Stages:** Allow workspace admins to define custom columns beyond the default (New, In Progress, In Review, Done) to match their specific agency processes.
6. **Automated Status Triggers:** Automatically move a ticket to "In Review" when a design file is attached, or to "Done" when the client approves the CDR.
7. **Ticket Dependencies:** Link tickets together (e.g., "Blocks", "Blocked By", "Relates To") to better visualize project constraints.

## ⏱️ Performance & Time Tracking
8. **Advanced Capacity Forecasting:** Predict workload bottlenecks based on average time-to-completion per designer and their current active timers.

## 🎨 Design Review & Proofing
11. **Figma / Canva Live Embeds:** Allow users to paste a design tool link and render an interactive iframe directly inside the Ticket Detail page.
12. **Pinpoint Visual Comments:** Let users click directly on an uploaded image or proof in the Ticket Detail page to leave a contextual comment pin (e.g., "Change this button to blue").
13. **Version Control for Assets:** Keep a history of uploaded files (v1, v2, v3) so teams can compare iterations side-by-side during the CDR phase.

## 🔔 Notifications & Collaboration
14. **Slack / Microsoft Teams Integration:** Push notifications to a Slack channel when high-priority SLA tickets are created or when a ticket becomes overdue.
15. **@Mentions in Comments:** Allow typing `@Name` in ticket comments to send an immediate push or email notification to that specific team member.
16. **Email-to-Ticket Creation:** Provide a dedicated workspace email address (e.g., `requests@mccia.in`) that automatically converts incoming emails into "New" tickets.

## 📊 Analytics & Reporting
17. **SLA Adherence Dashboard:** A visual chart showing the percentage of tickets completed within SLA over the last 30, 60, and 90 days.
18. **Designer Velocity Metrics:** Calculate the average time invested per ticket type (e.g., Landing Page vs. Social Media Graphic) to better estimate future work.

## 🛠️ UX/UI Enhancements
19. **Dark Mode Toggle:** A user preference switch in the header to invert the MCCIA theme colors for late-night designing.
